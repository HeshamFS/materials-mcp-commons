# Contributing

Materials MCP Commons is currently a single-author implementation maintained by Hesham Salama.

Code and documentation contributions are not currently accepted. Any change to this rule requires an explicit update to the project's authorship policy before contributions are accepted.

Once the public issue tracker is available, reproducible bug reports, interoperability observations, source corrections, and scientific-review feedback are welcome. Do not include credentials, private data, restricted datasets, proprietary solver files, or unpublished results.
