# Profile 0.2.0 policy cases

This directory contains non-scientific policy records used to exercise the 0.2.0 context and compatibility contracts.

- [`context-manifest.json`](context-manifest.json) declares the current bounded discovery, activation, lease, inline-result, and total-context policy.
- [`profile-compatibility.json`](profile-compatibility.json) partitions the successor resources into carried, changed, and added sets and declares the explicit 0.1.0-to-0.2.0 migration behavior.

These records exercise the context, compatibility, and schema-index contracts.
