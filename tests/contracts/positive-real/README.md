# Positive real corpus

Every directory in this corpus must contain an authoritative real record and:

- a canonical, versioned or revision-pinned source;
- source and local-mirror byte counts and SHA-256 digests;
- license or access rights and required attribution;
- an explicit transformation record;
- units, conditions, uncertainty or quality state, and limitations; and
- a statement of exactly what the fixture does and does not prove.
