# Positive project-control runtime corpus

This directory contains valid project-owned control-plane records derived from behavior implemented in the repository. It is separate from the positive scientific corpus because it makes no scientific or numerical claim.

The records are not a sample scientific backend, external integration, or substitute for later real-plugin evidence. They exist to exercise the generic engine boundary against its own actual discovery and lifecycle behavior without inventing a provider or fabricated scientific result.

The `engine-lifecycle/` and `engine-lifecycle-profile-0.1.0/` packages declare the same implemented discovery and inspection behavior against exact Profile 0.2.0 and 0.1.0 contracts. Their explicit comparison is the positive plugin-package migration case.
